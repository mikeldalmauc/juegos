# Decisiones

## D-01 · Web estática en GitHub Pages, sin build (11/11/2026)
HTML, CSS y JS a pelo, publicados desde la raíz de `main`. Así no hay nada que instalar ni que compilar, y basta con un `git push` para publicar. El repo es público porque GitHub Pages en la cuenta gratuita solo publica repos públicos.

## D-02 · Un juego por carpeta (11/11/2026)
Cada juego va en su carpeta con su `index.html` y la portada (`index.html` de la raíz) enlaza a todos. Cada juego queda con su propia URL y no se pisan unos con otros.
